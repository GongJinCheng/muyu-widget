# 木鱼挂件 · Muyu Widget

在任意网页上挂一只可敲、可拖、可抛的木鱼。Chrome / Edge，Manifest V3。

## 安装（加载已解压的扩展程序）

1. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`）。
2. 打开右上角 / 左侧的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录（含 `manifest.json` 的那一层）。
4. 打开任意网页（`chrome://` 等内置页除外），木鱼会出现在右下角。

## 使用

| 操作 | 效果 |
| --- | --- |
| 单击木鱼 / 鱼 | 敲一下：形变回弹 + 涟漪 + 工具挥动 + Web Audio 合成的叩击声，上方飘出「功德 +1」（鱼为「摸鱼 +1」） |
| 连续快速敲击 | 每次都会飘字，多个飘字错开位置叠加上浮，互不遮挡 |
| 按住拖动 | 完全跟手；可拖到视口内任意位置，慢慢放下就停在原地（不掉落、不漂移） |
| 快速甩出 | 按松手速度飞出：重力下落、撞墙/落地回弹、旋转、阻尼，落地后自然停住 |
| 位置记忆 | 停下的位置会被记住，下次打开网页时还在那里 |
| 悬停本体 | 左上角出现两个按钮：⚙ 设置、⌄ 收起 |
| 设置面板 | 点齿轮展开，分四组：形象 / 敲击 / 功德数据 / 功德卡；点面板外、敲击或开始拖动都会自动收起 |
| 换形象 | 「对象」木鱼 / 鱼，「工具」木槌 / 手，可自由组合；选「鱼」时飘字变成「摸鱼 +1」，卡片文案也随形象变 |
| 自动敲击 | 面板里打开开关，按选定节奏自动敲（动画 + 音效 + 飘字）；再关一次立即停止 |
| 节奏 | 慢 1.4s / 标准 0.9s / 快 0.6s / 连击 0.4s，改完立刻按新节奏走 |
| 每日目标 | 面板里直接改数字（1–9999），进度环、百分比与「还差 N 下」即时更新 |
| 收起后 | 变成一个圆形小图标，点它即可展开；收起期间自动敲击暂停，展开后按原状态继续 |
| 滚动页面 | 挂件固定在视口，不会随页面滚走 |
| 保存功德卡 | 面板底部一键导出 1080×1440 PNG，含标题、日期、当前形象、今日/累计/连续天数/目标进度与页脚 |

位置、收起状态、静音、自动开关、节奏、当前形象、每日目标、自定义文案和功德数据都会自动保存，下次打开网页时恢复。

## 文案自定义

- 卡片文案默认跟着形象走：木鱼是「功德 / 今日功德 / 累计功德 / 连续敲击」，鱼是「摸鱼 / 今日摸鱼 / 累计摸鱼 / 连续摸鱼」，页脚同为「木鱼挂件 · 敲一下，功德 +1」或「摸一下，摸鱼 +1」。
- 设置面板「功德卡」一栏就是一张接近成品的卡片预览：**点标题、今日标签、三列小标签或页脚，即可就地输入**，回车或点开别处保存，Esc 取消（最多 6/8/30 字，超长自动截断）。
- 只有你改过的字段会被记住，其余字段继续跟随当前形象自动变化；换形象时自定义的那几处保持不变。
- 「恢复默认」一键清空全部自定义，回到当前形象的默认文案。
- 导出的图片使用当前生效的文案。

## 功德数据

- 每日目标默认为 **108**，可在设置面板改成任意 1–9999 的数字；「今日」在本地时间零点归零。
- **累计**只增不减；**连续天数**要求当天敲过至少一下，隔一天没敲就归零重新计算。
- 数据存两份：`chrome.storage.local` 立即写入（关页面/刷新不丢），`chrome.storage.sync` 每 4 秒合并写一次，登录同一账号的其他设备会自动合并（计数器取较大值，日期与目标取较新值）。
- 功德卡在本地用 Canvas 绘制：形象取自当前皮肤的内联 SVG，文字用系统字体，不请求任何网络资源，断网也能导出。

## 说明

- 页面上只有本体 + 两个按钮（⚙ 设置 / ⌄ 收起），其余功能全部收在设置面板里；面板尺寸克制（252px 宽、最高 76vh、内容超高时面板内滚动），展开方向会自动避让视口边缘，必要时改贴到本体侧面。
- 样式全部封装在 Shadow DOM 中（`z-index: 2147483647`），不会污染或影响宿主网页。
- 音效由 Web Audio API 实时合成（三角波 + 正弦 + 带通噪声），不加载任何外部音频文件。
- 皮肤是数据驱动的：`content.js` 里的 `SUBJECTS` / `TOOLS` 注册表，每项只描述「图形 + 文案 + 敲击形变 / 挥动轨迹 / 落点」，新增形象（铜钟、猫爪…）只需追加一项数据（含默认卡片文案），交互逻辑不用改。
- 木鱼本体是内联 SVG：径向渐变做木色、叠层木纹、倒角描边、内阴影与投影；敲击时按落点弹出涟漪，并做一次“压扁—回弹”的形变。
- 物理为自写的定步长积分（重力 2600 px/s²、地面回弹 0.56、空气与旋转阻尼），不依赖任何 CDN 或第三方库，可完全离线运行。
- 仅申请 `storage` 权限（记住位置 / 状态 / 功德数据 / 文案），不注入远程代码，不读取页面内容。
