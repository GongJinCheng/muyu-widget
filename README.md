# 木鱼挂件 · Muyu Widget

在任意网页上挂一只可敲、可拖、可抛的木鱼。Chrome / Edge，Manifest V3。

## 安装（加载已解压的扩展程序）

1. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`）。
2. 打开右上角 / 左侧的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录（含 `manifest.json` 的那一层）。
4. 打开任意网页（`chrome://` 等内置页除外），木鱼会出现在右下角。

## 使用

| 操作 | 效果 |
| --- | --- |
| 单击木鱼 / 鱼 | 敲一下：形变回弹 + 涟漪 + 工具挥动 + 合成的木质叩声，上方飘出「功德 +1」（鱼为「摸鱼 +1」） |
| 键盘 `Tab` 聚焦后按 `回车` / `空格` | 同样敲一下；**长按可连续敲**，越按越快 |
| 方向键 / `Shift` + 方向键 | 微调挂件位置（每次 8px / 24px），纯键盘也能摆位置 |
| 连续快速敲击 | 每次都会飘字，按 5 个槽位横向错开 + 纵向抖动，互不遮挡 |
| 按住拖动 | 完全跟手；可拖到视口内任意位置，慢慢放下就停在原地 |
| 快速甩出 | 按松手速度飞出：重力下落、撞墙/落地回弹、旋转、阻尼，落地后自然停住 |
| 位置记忆 | 停下的位置会被记住，下次打开网页时还在那里 |
| 悬停本体 / 键盘聚焦 | 左上角出现两个按钮：⚙ 设置、⌄ 收起 |
| 设置面板 | 点齿轮展开，分四组：形象 / 敲击 / 功德数据 / 功德卡；点面板外、敲击或开始拖动都会自动收起 |
| 换形象 | 「对象」木鱼 / 鱼，「工具」木槌 / 手，可自由组合；选「鱼」时飘字变成「摸鱼 +1」 |
| 自动敲击 | 面板里打开开关，按选定节奏自动敲；再关一次立即停止 |
| 节奏 | 慢 1.4s / 标准 0.9s / 快 0.6s / 连击 0.4s，改完立刻按新节奏走 |
| 每日目标 | 面板里直接改数字（1–9999），进度环、百分比与「还差 N 下」即时更新 |
| 保存功德卡 | 面板底部（常驻按钮）一键导出 1080×1440 PNG |

位置、收起状态、声音开关、自动开关、节奏、当前形象、每日目标、自定义文案和功德数据都会自动保存。

## 设计说明

### 视觉：宋器 · 金木

木鱼按传统「团鱼形木鱼」的真实结构重绘，三层缺一不可：

1. **圆鼓木身**，正脸雕满扇形鳞片 —— 撑住体量感；
2. **上部一道深色出音缝** —— 最关键的识别点；
3. **缝上方鱼头卷起的两个瓣** —— 把它从「罐子」里救出来。

104px 下如果少了缝或瓣，它就会退化成茶杯或笑脸贴纸，所以这几处是刻意保留的。材质走「紫檀木 + 墨影 + 描金」，在白底、深色、花哨的页面上都能立住。

设置面板采用**深墨底 + 金线**：浅米色面板在白底网页上几乎会消失，深色底则任何页面上都有明确边界；金色只用于激活态和数值，不当装饰铺满。

### 音效：模态合成

不采样、不加载文件，纯 Web Audio 实时合成一块被敲击的空心木头：

- **敲击瞬态**：极短的低通噪声，只负责「咔」那一下接触感；
- **腔体基频**：正弦 + 起音略高再落下，木鱼空腔的主音高；
- **木体泛音**：2.76 / 5.4 / 8.9 倍**非整数倍**泛音 —— 这是木头区别于金属/玻璃的关键，整数倍会听起来像铃声；
- **余响**：基频带轻微频率漂移，模拟敲完后的木头嗡鸣。

每一下的基频（±5%）、泛音强度、噪声量都有微小随机，连击不会像机关枪。木鱼与锦鲤各有一套音色参数（`tone`）。

### 飘字：三层才立得住

浮在任意页面上，浅背景时金色会「化掉」，所以用**细描边（1px 半透明棕）切出轮廓 + 亮色字身 + 暖光晕提气**。动画是起手弹到位 → 匀速上浮 → 淡出时再放大一点，视线会跟着走。「功德」与「+1」分成两段，数字更大更亮形成主次。同屏最多 12 个，超出即淘汰最旧的。

### 无障碍

- 本体是 `div[role=button][tabindex=0]`，`aria-label` 说明操作方式，`aria-keyshortcuts` 声明快捷键；
- 回车/空格敲击，**按住连发**（380ms 后开始，140ms 一次），走的是与鼠标相同的 `knock()` 路径；
- 方向键微调位置，解决纯键盘用户无法拖动的问题；
- 自绘 `:focus-visible` 焦点环（2px 金色 + 外扩光晕），因为宿主页面的样式经常冲掉系统焦点环；
- `prefers-reduced-motion: reduce` 下所有位移/缩放动画压到 1ms，飘字改为纯淡出（仍然可见）。

## 文案自定义

- 卡片文案默认跟着形象走：木鱼是「功德 / 今日功德 / 累计功德 / 连续敲击」，鱼是「摸鱼 / 今日摸鱼 / 累计摸鱼 / 连续摸鱼」。
- 设置面板「功德卡」一栏就是接近成品的卡片预览：**点标题、今日标签、三列小标签或页脚，即可就地输入**，回车或点开别处保存，Esc 取消。
- 只有改过的字段会被记住，其余字段继续跟随当前形象；「恢复默认」一键清空。

## 功德数据

- 每日目标默认 **108**，可改成任意 1–9999；「今日」在本地时间零点归零。
- **累计**只增不减；**连续天数**要求当天敲过至少一下，隔一天没敲就归零重算。
- 数据存两份：`chrome.storage.local` 立即写入，`chrome.storage.sync` 每 4 秒合并写一次，多设备合并时计数器取较大值。
- 功德卡在本地用 Canvas 绘制，形象取自当前皮肤的内联 SVG，不请求任何网络资源，断网也能导出。

## 开发

### 目录结构

```
muyu-widget/
├── manifest.json     # MV3 配置
├── stats.js          # 功德数据层：G-Counter 合并 + 目标仲裁（纯函数，可被 Node 单测）
├── art.js            # 美术资产：形象/工具/图标的 SVG + 文案 + 敲击参数（纯数据）
├── content.js        # 挂件注入、物理、音效、交互、设置面板、功德卡
├── styles.css        # Shadow DOM 内部样式
├── icons/            # 16 / 32 / 48 / 128 图标
├── privacy.html      # 可直接托管的隐私政策页
├── STORE-LISTING.md  # 上架文案（单用途说明、权限理由、隐私政策，可直接粘贴）
├── ROADMAP.md        # 后续开发计划
└── tools/            # 本地验收与打包工具（不进扩展包）
```

三个模块各司其职，改动互不牵连：
- `stats.js` 管数据合并（多标签页/跨设备不丢计数），`tools/stats.test.js` 可直接单测；
- `art.js` 管美术，`tools/art.html` 可大图预览；
- `content.js` 只管交互与渲染。

### 验收工具

扩展没有构建步骤，`tools/` 下是零依赖的本地验收脚本，需要 Node 18+ 和一个 Chrome/Edge。

```bash
# 1) 起静态预览服务（默认 8899）
node tools/serve.js

# 2) 另开一个无头 Chrome，暴露 CDP
"C:/.../chrome.exe" --headless=new --no-sandbox --remote-debugging-port=9333 \
  --user-data-dir=/tmp/cdp about:blank
```

然后：

| 命令 | 用途 |
| --- | --- |
| `node tools/stats.test.js` | **数据层单测**（17 项）：G-Counter 并发合并、目标仲裁、v1 迁移、脏数据、连续天数 |
| `node tools/smoke.js` | **交互冒烟测试**（18 项）：注入、键盘敲击、飘字、涟漪、换形象、面板、收起展开 |
| `node tools/deep.test.js` | **深度功能测试**（16 项）：功德卡 Canvas 导出、卡片文字键盘编辑、Escape、目标、减弱动态 |
| `node tools/tabs.test.js` | **多标签页一致性**：并发敲击不丢计数、切回标签页主动同步、刷新后持久化 |
| `node tools/verify-store-shots.js` | 商店截图内容校验（22 项） |
| `node tools/check.js` | 静态自检：manifest / 图标 / 语法 / id 与类名双向对账 |
| `node tools/verify-extension.js` | **真实扩展环境验收**：加载未打包扩展，确认注入、CSS 加载、尺寸正确 |
| `node tools/pack.js` | 打商店提交用的 zip 到 `dist/`（自动剔除开发文件并校验） |
| `node tools/pack.js --check` | 只校验、不打版 |
| `node tools/store-shots.js` | 生成 5 张商店截图到 `tools/shots/store/` |
| `node tools/icons.js <源图>` | 从一张源图生成 16/32/48/128 四个尺寸 |
| `node tools/icons.js --verify` | 校验现有图标尺寸与 PNG 有效性 |
| `node tools/shot.js <png> [url]` | 整页截图 |
| `node tools/shot-knock.js <png>` | 敲击瞬间截图（抓住飘字与涟漪） |
| `node tools/shot-panel.js <png>` | 设置面板截图 |
| `node tools/eval.js "<js>"` | 在页面里执行表达式并回传结果 |

`stats.test.js` 不需要浏览器；其余 CDP 脚本需要预览服务（8899）和一个开了 `--remote-debugging-port=9333` 的 Chrome。`tabs.test.js` 例外，需要**加载了扩展**的 Chrome（默认 9444 端口）。

### 上架

提交流程、单用途说明、权限理由、隐私政策文案都在 [STORE-LISTING.md](STORE-LISTING.md)，可逐条粘贴进开发者后台。

```bash
node tools/pack.js        # → dist/muyu-widget-2.0.0.zip（manifest.json 在根目录）
```

Chrome 网上应用店与 Microsoft Edge 附加组件**共用同一个 zip**，Edge 可直接复用 Chrome 的 manifest，无需改代码。


验收页：`tools/preview.html`（模拟普通网页）、`tools/art.html`（美术大图）、`tools/contrast.html`（浅底/深底对比）、`tools/white.html`（纯白底）。

### 新增形象

在 `art.js` 的 `SUBJECTS` 里追加一项，描述「SVG + 文案 + 敲击形变 / 落点 / 音色」即可，交互逻辑不需要改：

```js
bell: {
  label: '铜钟',
  verb: '功德',
  copy: { title: '功德', today: '今日功德', total: '累计功德',
          streak: '连续敲击', goal: '目标完成', footer: '…' },
  svg: BELL_SVG,          // viewBox 0 0 120 120
  squash: [1.05, 0.92],   // 敲击瞬间的缩放峰值
  origin: '50% 80%',      // 形变原点
  impact: [50, 62],       // 涟漪落点（百分比）
  tone: { base: 720, ring: 2.4, thud: 0.2 }  // 基频 / 泛音比 / 闷度
}
```

### 已知取舍

- 平板宽度区间（约 700–1000px）面板偏窄，功德卡预览需要滚动才能看全；保存按钮已固定在底部常驻。
- 木鱼本体是内联 SVG（37 条 path），比位图灵活但体积略大；这是刻意选择，皮肤要能任意换色。
- 仅申请 `storage` 权限，不注入远程代码，不读取页面内容。
